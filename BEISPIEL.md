# Übersicht

**Saro's Example Mod** ist eine vielseitige Utility-Mod für Minecraft-Server und Singleplayer. Sie fügt neue dekorative Blöcke, nützliche Items und praktische Admin-Befehle hinzu.

## Hauptfunktionen

### 🧱 Neue Blöcke
*   **Leuchtblock**: Ein Block der in allen 16 Farben leuchtet
*   **Unsichtbarer Rahmen**: Perfekt zum Verstecken von Dekorationen
*   **Sitzblock**: Spieler können sich darauf setzen

### 🎒 Items
*   **Teleport-Stab**: Teleportiere dich 10 Blöcke in Blickrichtung
*   **Reparatur-Hammer**: Repariert Items sofort für XP

### ⌨️ Befehle
*   **Admin-Tools**: Befehle zum Verwalten des Servers
*   **Spieler-Utility**: Nützliche Befehle für alle

## Befehlsliste

| Befehl | Beschreibung |
| :--- | :--- |
| `/example reload` | Lädt die Konfiguration neu |
| `/example give <item>` | Gibt ein Mod-Item |
| `/sit` | Setzt dich auf den Block unter dir |

# Overview

**Saro's Example Mod** is a versatile utility mod for Minecraft servers and singleplayer. It adds new decorative blocks, useful items, and practical admin commands.

## Main Features

### 🧱 New Blocks
*   **Light Block**: A block that glows in all 16 colors
*   **Invisible Frame**: Perfect for hiding decorations
*   **Seat Block**: Players can sit on it

### 🎒 Items
*   **Teleport Staff**: Teleport 10 blocks in viewing direction
*   **Repair Hammer**: Instantly repairs items for XP

### ⌨️ Commands
*   **Admin Tools**: Commands for server management
*   **Player Utility**: Useful commands for everyone

## Command List

| Command | Description |
| :--- | :--- |
| `/example reload` | Reloads the configuration |
| `/example give <item>` | Gives a mod item |
| `/sit` | Sit on the block below you |
