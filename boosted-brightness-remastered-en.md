# Overview

**Boosted Brightness Remastered** is a useful utility mod that allows you to adjust the brightness in Minecraft far beyond the standard limits. It is ideal for players who want to see better in dark caves or simply need more control over their visual settings without relying on external shaders.

## Main Features

### 💡 Brightness & Configuration
*   **Extended Brightness**: Allows settings from -150% up to 1200% brightness (default max is 100%).
*   **Custom Levels**: Save and manage up to 5 different brightness presets.
*   **JSON Configuration**: All settings are stored in a clear configuration file.
*   **Overlay Display**: A subtle overlay informs you of the current brightness value when switching.

### ⌨️ Controls & Interface
*   **ModMenu Integration**: An intuitive GUI menu (accessible via ModMenu) to adjust, add, or remove brightness levels via sliders.
*   **Keybindings**:
    *   `B` (Default): Switches to the next saved brightness level.
    *   `]` (Default): Increases brightness incrementally.
    *   `[` (Default): Decreases brightness incrementally.
*   **Direct Selection**: Optional keybindings for directly selecting a specific brightness level (1-5).
